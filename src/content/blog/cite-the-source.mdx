A social post is a claim, in the same way an agent's "done" is a claim. You can quote it. The quote is not evidence that the work shipped, and it is not a customer result. On this site a quotation keeps the author, the date, and a permalink back to the original. There is no embed service behind the card. If the network is down, or there is no API key, the citation is still the text, the name, and the link.

The three cards below are specimens. The handles are not real accounts, and the lines were written for this page. They show the shape of a citation for X, LinkedIn, and any other URL.

A citation is not a PASS. PASS is still tied to a code revision and to checks the agent cannot forge. The graph that holds those links is append-only. SDF does not sell the agent that did the work, and the dollar amounts for SDF itself are not published.

This page is a sample. SDF runs live only on a toy fixture. If the record is the thing you want to baseline, [become a design partner](/design-partners).
